## 路由测试到底在看什么

很多人测路由只盯着 Ping 延迟看，其实那只是一半。真正要看的是**去程**（国内→服务器）和**回程**（服务器→国内）分别走哪条线路，因为很多便宜 VPS 去程给你 CN2 GIA 漂漂亮亮，回程却偷偷绕 163 或者 CMI 绕一大圈，晚高峰就原形毕露。

几个常见线路先科普下，后面看数据不懵：

- **CN2 GIA**：电信精品线路，延迟最低、稳定性最好，业内顶配级别
- **CMI**：中国移动国际出口，移动用户走这条最顺，联通电信也能用
- **AS4837 / CU169**：联通 169 骨干，联通用户的主力回程
- **AS10099 / CUG**：联通国际精品网，比 169 更优
- **AS9929**：联通高端线路，质量接近 CN2 GIA
- **AS163**：电信普通骨干，没优化，晚高峰容易堵

搞清楚这些，下面看各机房路由就明白了。

## 香港-KC 机房：三网直连，CN2 GIA 撑场子

KC 是狗云香港主推的精品机房，可选阿里云精品、BGP 优化、国际、纯 v6 等多条路线，还能加高防 IP。从实测看，它也是香港几个机房里线路最扎实的。

**去程路由**（以经典云精品套餐为例）：

- 电信：CN2 GIA / CTGNet 直连香港，走 AS4809
- 联通：AS10099（CUG）直连，香港落地点
- 移动：CMI 直连香港，走 AS58453

**回程路由**（北京、上海、广东三地 tracert 实测）：

- 电信回程：CN2 GIA 骨干（59.43 段），北京约 44ms，上海约 32ms，广东约 17ms
- 联通回程：AS10099→AS4837（169 骨干），北京约 47ms，上海约 39ms，广东约 21ms
- 移动回程：CMI 直连，北京约 49ms，上海约 31ms，广东约 23ms

整体 Ping 均值只有 44ms 左右，连续 Ping 70 次零丢包，稳定性相当能打。需要原生 IP 的话，选 4GB 内存及以上的套餐默认就给原生，流媒体解锁也更干净。

这条机房适合对延迟敏感、追求稳定三网直连的场景，比如建站、API 中转、远程办公。带宽端口偏小（25-50Mbps），大流量场景得考虑 MG 大带宽机房。

## 香港-MG 机房：大带宽是卖点，线路稳定性一般

MG 机房分 BGP 和 GB（国际大带宽）两个系列，最大能跑到 3000Mbps，是狗云香港带宽最猛的。但线路稳定性是它的短板。

**MG-BGP 路由实测**（2026 年最新数据）：

- 去程：电信 CN2、移动 CMI、联通 4837
- 回程：三网统一调整为联通 10099 回程

**MG-GB 路由**：

- 去程/回程：电信 163（普通骨干，没优化）、移动 CMI、联通 4837
- 移动用户在这条上"较为快乐"，电信用户晚高峰可能堵

digvps 长期观察的结论很直白：MG 线路**稳定性一般，常有断线或路由切换**。如果你追求稳定建站，KC 或 CLD 更合适；但如果你要大带宽跑量、做中转或者纯移动用户，MG 的性价比确实高，最低 25 元/月就能拿到 100Mbps。

## 香港-CLD 机房：老牌高性价比，线路够用

CLD 是狗云香港的老牌机房，主打高性价比，BGP 多线路优化。

**路由实测**：

- 去程：电信 CN2、移动 CMI、联通 4837
- 回程：电信 10099、移动 CMI、联通 10099

延迟表现和 KC 接近，线路优化到位，价格比 KC 还便宜（最低 25 元/月起）。缺点是带宽端口 50-80Mbps，不算大，而且据社区反馈"优化线路但偶尔挨打"，稳定性比 KC 略逊一筹。预算有限又想要三网直连的，CLD 是性价比之选。

## 韩国机房：弹性云和经典云线路有差异

这点容易被忽略——狗云韩国机房，**弹性云和经典云走的电信去程不一样**：

- 经典云电信去程：163（普通骨干，偶尔 CN2 点缀）
- 弹性云电信去程：CN2（Ping 能快几毫秒）

联通和移动两边一致：联通 4837，移动 CMI。回程电信此前还有 CN2，现已纯 163。韩国线路 IP 质量不错，可惜带宽口子只有 30-50Mbps，偏小。适合需要韩国原生 IP、低延迟东亚业务的场景。

## 美国洛杉矶机房：三网直连，自带 20G 防御

美国 LA 机房走 CN2 + CUII 优化线路，三网基本直连，国内访问延迟可控。最大亮点是**自带 20G DDoS 防御**，对建站防刷量比较友好。带宽 100Mbps，配置 1-8 核可选。适合外贸建站、对美国 IP 有需求、又怕被打的用户。

## 德国 / 日本机房：CN2 GIA 优化，欧洲日本业务首选

- **德国法兰克福**：走 CN2 GIA / CUII 线路，对国内三网有优化，适合欧洲业务 + 国内回程需求
- **日本大阪（DC2）**：BGP 路线，50Mbps 带宽，日本原生 IP，适合日本业务和亚太低延迟场景
